# Dhiman & Anamika — Interactive Wedding Invitation

A static, GitHub Pages-ready wedding invitation website built from the original Assamese invitation card for the wedding of **Dhiman Jyoti Das** and **Anamika Deka**.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design and animations
- `script.js` — countdown, card flip, flower interaction, petals, reveal animations and optional ambient chime
- `assets/invitation.jpg` — original invitation card

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `dhiman-anamika-wedding`.
2. Upload **all files and the `assets` folder** to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the public Pages URL.

No build step is required.
